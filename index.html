How it works

Identify or name a plant Take a photo and Pl@ntNet's neural network identifies the species (free API key required, takes 2 minutes to set up). Or just type the scientific name if you already know it.
We pull every specimen Specimen Finder queries GBIF — the global aggregator of biodiversity data — for preserved-specimen records of that species (up to 300 per search), plus context from POWO (Kew's plant checklist) and Wikipedia.
Unusual records are flagged Statistical analysis surfaces records that don't fit the pattern: outliers in geography, time, or data quality. Each flag shows its reasoning, links to the original specimen, and explains how you'd verify or disprove it.

About Specimen Finder

Specimen Finder is an open tool for finding unusual plant specimen records in the world's herbaria. It uses no proprietary data — everything comes from public, citable scientific sources. Built for botanists, herbarium curators, conservation biologists, students, and anyone curious about plants.

Data sources

  • GBIF — specimen records
  • POWO (Kew) — taxonomy
  • Pl@ntNet — photo ID
  • Wikipedia — context
  • Wikidata — conservation status
  • iNaturalist — common names

For researchers

  • Every flag is reproducible
  • Citation text per record
  • CSV export available
  • Direct links to source records
All data licensed CC BY or CC BY-NC by source institutions. Specimen Finder itself is an open tool — no accounts, no tracking, no ads. Your API key stays in your browser.

Set up photo identification

Photo identification uses Pl@ntNet — a research-grade neural network for plant ID used by botanists worldwide. You need a free API key (about 2 minutes to set up). The free tier allows up to 500 identifications per day.

  1. Open my.plantnet.org and click "Sign up"
  2. Verify your email and log in
  3. Go to your account → "API key"
  4. Copy that key and paste it below

Your key is stored only in this browser, never sent anywhere except directly to Pl@ntNet. You can change or remove it anytime.

Optional: share annotations with the community

If you want to contribute your "False positive / Confirmed / Needs review" annotations to the public community record, paste a GitHub Personal Access Token with public_repo scope. Reads are always public — you only need a token to post annotations. The token stays in your browser; it's never sent anywhere except directly to GitHub.

Recommended scope: public_repo only. The community archive lives at TheoryofShadows/specimen-finder-annotations.

About Specimen Finder

Plants matter to ecology, medicine, conservation, and food systems. Their records — physical specimens pressed and stored in herbaria, sometimes for centuries — are the foundation of botanical knowledge. But the records aren't perfect. Specimens get mislabeled, misidentified, or filed under outdated names. Important records sit in collections with no one able to flag what needs attention.

Specimen Finder is a small tool aimed at that gap. Given a species, it queries the global aggregated record (GBIF, which pulls from 1,800+ herbaria), and applies statistical checks to flag records that look unusual — far from the typical range, very early or very late dates, missing coordinates, data quality issues. Each flag includes its reasoning and a direct link to the source record so you can verify, dispute, or follow up.

The tool doesn't replace expert judgment. It surfaces candidates for it. Researchers can export results, cite specimens, and prioritize their attention. Curious people can see how the global botanical record actually works.

No data is stored on a server. No accounts. No tracking. Your Pl@ntNet API key, if you use one, lives only in your browser.
